# Линейная алгебра на Python

Разбираю линейную алгебру на практике с помощью Python.
Каждый ноутбук — одна тема: коротко теория, вычисления в коде, проверка результатов и выводы.

## Ноутбуки

| № | Тема | Что внутри |
|---|------|------------|
| 01 | [Метод главных компонент (PCA) и SVD](01_pca_svd.ipynb) | Стандартизация, поиск главных осей тремя способами (перебор углов, собственные векторы корреляционной матрицы, SVD), доля объяснённой дисперсии, сжатие данных до одной компоненты |

## Стек

Python, NumPy, Matplotlib, Jupyter

## Как запустить

```bash
pip install -r requirements.txt
```

Затем открыть нужный ноутбук в Jupyter или VS Code и запустить все ячейки.
